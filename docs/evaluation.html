Evaluation

Any question regarding Computer Networks outside laboratories should be addressed by email; it should have the subject beginning with [RC][yeargroup] and it should be signed with your name.

The final mark (N) for Computer Networks course is computed as follows:

N = 0.5*P+0.4*L+1

where:

  • P = a practical project. Details here

  • L = a mark for laboratory activities, which is calculated using the following criteria:

    • Mandatory problems during the semester;
    • Evaluation during the 5th and the 11th week;
    • Other laboratory activities;
    • Other individual activities. The mark for this component is the result of some special homework evaluation. The homework is to be proposed by course/laboratory teachers during the semester.
      A mark for this component will also be granted under the following circumstances:
      • Contributions to the kernel, components, libraries of a Linux operating system or various available distributions;
      • Administration of a public computer network;
      • Other specific activities: translations of the documentation, contributions to scientific papers et.al.

    The minimal mark to pass this course is at least 5 for the P component and at least 5 for the final score (N).

    The final mark for this discipline is computed consistent with ECTS, according to actual regulations.
